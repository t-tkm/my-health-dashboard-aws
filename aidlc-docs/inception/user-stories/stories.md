# User Stories

Story 形式: `As a [persona], I want to [action], so that [benefit].`
INVEST 基準（Independent / Negotiable / Valuable / Estimable / Small / Testable）に準拠。

---

## Epic 1: 認証

### US-01: サインイン
**As a** 健康管理ユーザー,  
**I want to** メールアドレスとパスワードでサインインできる,  
**so that** 自分のデータに安全にアクセスできる。

**Acceptance Criteria:**
- [ ] 未認証の場合、Cognito Hosted UI のログイン画面が表示される
- [ ] 正しい認証情報でログインするとダッシュボードが表示される
- [ ] 間違った認証情報ではエラーメッセージが表示される
- [ ] ログイン後は JWT が取得されてすべての API リクエストに自動付与される

---

### US-02: サインアウト
**As a** 健康管理ユーザー,  
**I want to** ログアウトボタンでサインアウトできる,  
**so that** 共有デバイスでも安心して利用できる。

**Acceptance Criteria:**
- [ ] ヘッダーのログアウトボタンをクリックすると認証状態がクリアされる
- [ ] ログアウト後はダッシュボードにアクセスできなくなる（ログイン画面にリダイレクト）

---

## Epic 2: データ閲覧

### US-03: ダッシュボード表示
**As a** 健康管理ユーザー,  
**I want to** ログイン後に全期間の健康データがダッシュボードに表示される,  
**so that** 自分の健康トレンドを一覧で把握できる。

**Acceptance Criteria:**
- [ ] ログイン後、サマリーカード（最新体重 / 平均カロリー / 記録日数）が表示される
- [ ] 体重推移グラフ（日次体重 + 7日SMA）が表示される
- [ ] 体重増減ペースグラフ（週次棒グラフ）が表示される
- [ ] 栄養素グラフ（カロリー / タンパク質 / 脂質 / 炭水化物 / 糖質 / 食物繊維 / 塩分）が表示される
- [ ] データが存在しない場合はデータ入力を促すエンプティステートが表示される

---

### US-04: 期間フィルター
**As a** 健康管理ユーザー,  
**I want to** 表示期間（30日 / 90日 / 半年 / 1年 / 全期間）を切り替えられる,  
**so that** 短期・長期のトレンドを使い分けて分析できる。

**Acceptance Criteria:**
- [ ] 期間ボタンを切り替えるとグラフとサマリーカードが連動して更新される
- [ ] 選択した期間のデータ日数がサマリーカードに表示される
- [ ] 全体のレコード日数はサマリーカードに常に表示される
- [ ] デフォルトは全期間表示

---

### US-05: レスポンシブ表示
**As a** 健康管理ユーザー,  
**I want to** スマートフォンでもダッシュボードを確認できる,  
**so that** 毎朝の体重入力後すぐに結果を確認できる。

**Acceptance Criteria:**
- [ ] 600px 未満ではグラフの高さが縮小されモバイル向けレイアウトになる
- [ ] すべてのグラフ・ボタンがスマートフォンで操作できる

---

## Epic 3: データ入力・管理

### US-06: 体重・食事データ入力
**As a** 健康管理ユーザー,  
**I want to** モーダルフォームから日付を指定して体重・栄養素データを入力できる,  
**so that** 日々の記録をアプリから直接管理できる。

**Acceptance Criteria:**
- [ ] 「データを入力する」ボタンでモーダルフォームが開く
- [ ] 日付・体重・カロリー・各栄養素・各目安値を入力できる
- [ ] 体重か栄養素のどちらか一方のみの入力も可能
- [ ] 保存後にダッシュボードが自動リフレッシュされる
- [ ] 同一日付のデータは上書き（upsert）される
- [ ] 目安値を入力しない場合、前回の目安値が自動引き継ぎされる

---

### US-07: データ削除
**As a** 健康管理ユーザー,  
**I want to** 指定した日付のデータを削除できる,  
**so that** 誤入力したデータを修正できる。

**Acceptance Criteria:**
- [ ] EntryForm から指定日のデータを削除できる
- [ ] 削除後にダッシュボードが自動リフレッシュされる
- [ ] 全データ削除後はエンプティステートが表示される

---

## Epic 4: データ移行

### US-08: CSV エクスポート
**As a** 健康管理ユーザー,  
**I want to** 全データを CSV ファイルとしてダウンロードできる,  
**so that** データのバックアップや他ツールへの移行ができる。

**Acceptance Criteria:**
- [ ] 「CSV エクスポート」ボタンで health_data.csv がダウンロードされる
- [ ] ファイルは UTF-8 BOM 付きで Excel で文字化けなく開ける
- [ ] 全レコードが日付昇順で含まれる

---

### US-09: CSV インポート
**As a** 健康管理ユーザー,  
**I want to** 日本語カラム名の CSV ファイルをインポートできる,  
**so that** 旧システムや他アプリのデータを一括移行できる。

**Acceptance Criteria:**
- [ ] 「CSV をインポートする」ボタンでファイル選択ダイアログが開く
- [ ] UTF-8 / UTF-8 BOM / Shift-JIS の CSV が正常にインポートされる
- [ ] 日付フォーマット `YYYY/M/D` が自動変換される
- [ ] インポート完了後にダッシュボードが自動リフレッシュされる
- [ ] インポートエラーの場合はアラートが表示される

---
