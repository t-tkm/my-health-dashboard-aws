# Personas

## Persona 1: 健康管理ユーザー（Primary）

| 項目 | 内容 |
|---|---|
| **名前** | 田中 健（仮名）|
| **役割** | ダッシュボードの主利用者（健康管理を行う本人）|
| **年齢層** | 30〜50代 |
| **技術リテラシー** | 一般的な Web アプリ操作ができる。CSV 操作の経験あり |

### 目標
- 毎日の体重・食事データを手軽に記録したい
- 体重の長期トレンドを視覚的に把握したい
- 栄養摂取が目標に対してどの程度か確認したい
- データをスマートフォンでも確認したい

### 課題・ペイン
- 体重の日々のブレが大きく、本当に痩せているのかわかりにくい
- 食事記録アプリのデータをこのダッシュボードに移行したい
- 長期間記録が蓄積されたときにデータをバックアップしたい

### 利用シナリオ
1. 毎朝体重を測定後、スマホから体重データを入力する
2. 週に1〜2回、栄養素グラフを確認して食生活を振り返る
3. 月に1回、30日フィルターで体重トレンドを確認する
4. 年に1回、CSV エクスポートでデータをバックアップする

## Persona 2: システム管理者（Secondary）

| 項目 | 内容 |
|---|---|
| **名前** | 田中 健（本人兼任）または家族・友人 |
| **役割** | AWS インフラの管理・ユーザー作成 |
| **技術リテラシー** | AWS / CDK の基本操作ができる。コマンドライン操作に慣れている |

### 目標
- AWS リソースを低コストで維持したい
- 新しいユーザーを必要に応じて Cognito に追加したい
- インフラの変更を安全に CDK でデプロイしたい

### 課題・ペイン
- セルフサインアップを無効にしているため、ユーザー追加は手動で行う必要がある
- CDK デプロイは2ステップ手順が必要で手間がかかる
- テストがないため変更時のリグレッションが不安

### 利用シナリオ
1. 新しいユーザーを Cognito コンソールで作成する
2. 機能追加時に CDK でインフラ変更をデプロイする
3. コスト確認のために AWS コンソールで使用量を確認する
